# MealMind 🍱

Because deciding what to eat shouldn't be the hardest part of your day.

MealMind is a simple, no-nonsense meal planner designed to help you get your kitchen life together. Whether you're trying to hit macros, save some cash by not ordering takeout (again), or just want to stop staring at the fridge at 7 PM, this is for you.

---

## 🚀 Why use this?

* **Actually useful planning:** No clutter, just your meals and your schedule.
* **Recipe Vault:** Keep all those "I'll definitely cook this" recipes in one spot.
* **Auto-Shopping Lists:** It figures out what you need so you don't forget the garlic for the third time this week.
* **Diet-Friendly:** Set your preferences and stick to them.

## 🛠️ Built with...

* **React + Vite** (Fast and smooth)
* **Tailwind CSS** (Because it looks better that way)
* **TypeScript** (To keep things from breaking)
* **Lucide React** (Pretty icons)

## 💻 Get it running locally

1.  **Grab the code**
    ```bash
    git clone https://github.com/Arundhuti2000/mealmind.git
    cd mealmind
    ```

2.  **Get the dependencies**
    ```bash
    npm install
    ```

3.  **Start the magic**
    ```bash
    npm run dev
    ```
